# Tasks, Files, and Comments

Core building blocks of every Acme Cloud project.

## Tasks

Fields: title, description, assignee, due date, status.

Statuses:

| Status | Meaning |
|---|---|
| `todo` | Not started |
| `in_progress` | Being worked on |
| `blocked` | Waiting on something else |
| `done` | Completed |

- Assign one member per task.
- Due dates accept any future or past date; overdue tasks are highlighted.
- Bulk actions (edit status, reassign) are available on Pro and Enterprise.
- Tasks appear in search within a few minutes of changes.

## Files

- Files are uploaded to a project and versioned automatically.
- Version history keeps the last 10 versions per file.
- Deleted files stay in the project trash for 30 days before permanent deletion.

| Limit | Free | Pro | Enterprise |
|---|---|---|---|
| Max file size | 25 MB | 1 GB | 5 GB |
| Workspace storage | 2 GB | 100 GB | Custom |

## Comments

- Comments are real-time; everyone viewing the project sees them immediately.
- Use `@mention` to notify a member; they receive an email and in-app notification.
- Markdown is supported in comments.
- Edited comments keep history for 30 days.
