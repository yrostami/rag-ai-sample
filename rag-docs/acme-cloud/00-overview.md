# Acme Cloud Overview

Acme Cloud is a fictional SaaS platform for team collaboration, file sharing, and project tracking.

## Core concepts
- **Workspace**: A container for projects, members, and billing.
- **Project**: A collection of tasks, files, and comments.
- **Member**: A user invited to a workspace.
- **API Key**: A secret token used to access the Acme API.

## Who it is for
Small teams, engineering groups, and operations teams that need a simple collaboration hub.

## Key features
- Real-time comments
- File sharing
- Role-based access control
- REST API
- CSV/JSON export

## At a glance
- Regions: `us-east` and `eu-west`; data residency is pinned when the workspace is created and cannot be changed later.
- Storage quotas: Free 2 GB, Pro 100 GB, Enterprise custom.
- Sessions last 7 days.
- Status page: `status.acme.example`.
