# Getting Started

1. Create an account at `app.acme.example`.
2. Create a workspace.
3. Invite members from **Settings > Members**.
4. Create your first project.
5. Generate an API key from **Settings > API Keys**.
6. Use the API base URL: `https://api.acme.example/v1`.

## First project checklist
- Add a project name and description.
- Assign at least one member.
- Upload a sample file.
- Create a test task.

## Recommended next steps
- Enable two-factor authentication under **Settings > Security**.
- Pick your region (`us-east` or `eu-west`) before inviting the team; it is pinned at workspace creation.
- Turn on notifications or a daily digest under **Settings > Notifications**.
- Connect one integration (Slack, GitHub) under **Settings > Integrations**.
- Import existing tasks from CSV with **Settings > Import** if you are moving from another tool.
